# RayNu-V customer documents

Shipment 1 documents for an operator. These are not the lab runbooks in `docs/runbooks/`.

| Document | What it is for |
|----------|----------------|
| [Install](install.md) | Put a signed EFI on a PowerEdge R640 and open the page |
