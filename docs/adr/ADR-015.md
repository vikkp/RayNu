# ADR-015: Stage 46 close path is PR #229

- **Status:** Accepted
- **Date:** 2026-09-01
- **Pillars:** [Z] [A] ([V] unchanged — no Proven Core expansion)
- **Parent:** [ADR-009](ADR-009.md) · [ADR-014](ADR-014.md)

## Context

Stage 46 closes only on iron `RAYNU-V-M7-ISO-INSTALL-OK`. Host/CI still
never prints that marker. Stamp persist (`ISO-BOOTED-FROM-DISK`) is not
this gate.

Nested dumps at `de5fee7` and `30ccfc0` reach IdeBus **ParseBar**, then
stay `cmdwr=0` / `ataio=0`. Iron COM2 `184ee61` is different: firmware
wrote IDE COMMAND six times (`cmdwr=6`), last `wr=0x0`, stored
`pcicmd=0x1` because the emulator ORed `0x0001`. Nested `cmdwr=0` is
not the iron picture. Further IdeBus PCI slices on
[#231](https://github.com/vikkp/RayNu/pull/231) do not move that
picture. Dump criteria and the stop rule live in operator note
**STAGE46_WALL** — do not duplicate them here.

Two stacked drafts: [#229](https://github.com/vikkp/RayNu/pull/229)
(`cursor/e5-stage46-iso-a623`, fw_cfg / ACPI) and #231
(`cursor/e5-pm1-sci-a623`, IdeBus / SCI). This ADR names the path. It
does **not** close Stage 46.

## Decision

1. **Park #231.** No rebase, no merge, no new SHA on
   `cursor/e5-pm1-sci-a623`. Iron COM2 `c144001` restored
   EnableAttributes `0x0005` (`pcicmd=0x5`) after six write-0s.
   `ataio` stayed 0. COMMAND.IO is closed. Do **not** resume #231
   for further `COMMAND.IO` (that is the IdeBus farm). Stay on
   #229. Iron COM2 `118edcf` printed HLT `romwr=0xfffffffe`
   (ROM size probe, enable bit clear). Still `ataio=0`. CF8/ROM
   prints are closed.    Iron COM2 `27eda8c` hid slot-0 (CDROM-OK via
   PIIX) and still `ataio=0`. BAR conflict is closed. Iron COM2
   `2d4ab51` printed HLT `ret=0x7ff0e055` (DxeCore WaitForEvent, not
   PciBus) and still `ataio=0`. Iron COM2 `6c4bfde` pushed firmware
   ConIn CR; the CR printed and the same hang stayed `ataio=0`.
   DxeCore wait is a **timer** WaitForEvent, not serial ConIn.
   ConIn CR is closed (keep the one-shot). Iron COM2 `0b770cd`
   printed `rethx=0xe056ff41b84d8b48` (`call [r14-0x20]` CpuSleep).
   Callsite print is closed. Iron COM2 `e0d5c55` forced
   WaitForEvent return (`caller=0x7feffe28`); hang moved to EPT
   `reason=0x34` `rip=0x7ec8f6ff` (`xor eax,eax; mov [rbx],eax`)
   still `ataio=0`. WFE unwind is closed. Next is firmware
   ZeroMem ept fill. Do **not** hide PIIX. Keep hide-slot0.

2. **Close path is #229.** The live work is fw_cfg `rep insb` so OVMF
   can `InstallQemuFwCfgTables`. fw_cfg is a QEMU/OVMF bring-up shim,
   not the product ABI — see **FWCFG_PRODUCT_STANCE**.

3. **Do not claim `RAYNU-V-M7-ISO-INSTALL-OK`.**

4. **HDA `last_commit` stays `2b795a0`** (P0-14 E4 iron pin).

  (`rethx=0xe056ff41b84d8b48` still `ataio=0`). Do not F11
  `--run 33699177232` / `6c4bfde` again
  (ConIn CR fired; timer Wait still `ataio=0`). Do not F11
  `--run 33697154185` / `2d4ab51` again
  (`ret=0x7ff0e055` still `ataio=0`). Do not F11
  `--run 33695570769` / `27eda8c` again
  (hide-slot0 still `ataio=0`). Do not F11
  `--run 33630723649` / `118edcf` again
  (`romwr=0xfffffffe` size probe still `ataio=0`). Do not F11
  `--run 33627470674` / `7ba1ccf` again
  (`cf8ide=0x80000930` PIIX ROM BAR still `ataio=0`). Do not F11
  `--run 33575888121` / `5de9e1c` again
  (`cf8en=0x80004008` host class still `ataio=0`). Do not F11
  `--run 33573126367` / `61991be` (`cf8=0x0` still `ataio=0`).
  Do not F11 `--run 33571164257` / `c144001`
  (`pcicmd=0x5` still `ataio=0`). Do not F11 `--run 33569757025` / `060c504`
  (`seq=0,0,0,0,0,0`). Do not F11 `--run 33567464001` / `abba969`
  (honor `pcicmd=0` `wr=0` still `ataio=0`). Do not F11
  `--run 33562028442` / `184ee61` (`cmdwr=6` last `wr=0x0` stored
  `0x1`). Do not F11 `--run 33559849096` / `21dc562` (skip-HLT after

  while parked.
- Proven Core, ADR-002, and ADR-003 size are unchanged.
