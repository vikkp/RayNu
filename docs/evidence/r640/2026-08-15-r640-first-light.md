## Residuals fixed during the session

| Symptom | Cause | Fix kit |
|---------|-------|---------|
| Freeze at M0 on SOL/HTML5 | ConOut ≠ COM2; HV only wrote COM1 | `v0.1.0-com2` |
| EPT violation GPA high, rip ~5 GiB | Frame pool at multi-GiB HPA; identity EPT `[0,512MiB)` | `v0.1.0-eptfix` |
| `no virtio-blk BAR hole above G0 guest RAM` | Pool filled to 512 MiB, owned BAR window | `v0.1.0-barfix` |
| EPT violation walking `cr3=0x47e01000` | Guest shared host CR3 outside 512 MiB | `v0.1.0-cr3fix` |
| Silence after VMLAUNCH / HLT (no VMEXIT log) | `HOST_CR3` set to guest precise CR3 | `v0.1.0-hostcr3fix` |
| TIMER-OK then I/O+CPUID gate fail | naked GPR save used abs32 @ `0x40…` vs image `0x140…` | `v0.1.0-gprsfix` |
| Linux `PANIC: early exception 0x06` (`66 0f 38 82`) | INVPCID #UD — secondary Enable INVPCID off | `v0.1.0-invpcidfix` |
| APIC-OK then quiet; no SHELL | earlyser unregistered; 8250 console may stall on TX IRQ | `v0.1.0-keepconfix` |
| `Run /init` then TASK stack guard / panic in interrupt | XSAVES #UD (compacted XSAVE) without secondary bit 20 | `v0.1.0-xsavesfix` |
