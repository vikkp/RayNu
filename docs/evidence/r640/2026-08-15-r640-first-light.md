## cr3fix serial (silence after VMLAUNCH)

```text
boot: guest CR3 (precise identity)=0x…   # in-window
…
boot: VMLAUNCH → guest store+loop+HLT…
# no boot: VMEXIT phase=… / RAYNU-V-M1-VMEXIT-OK
```

Diagnosis: `HOST_CR3` reused guest CR3 → host page-faults on VMEXIT resume
when EFI/IDT live above 512 MiB. Fixed by `v0.1.0-hostcr3fix`.

## hostcr3fix serial (TIMER-OK then I/O/CPUID fail)

```text
RAYNU-V-M1-VMEXIT-OK … RAYNU-V-M2-TIMER-OK
boot: ERROR — guest COM1 I/O magic missing
boot: ERROR — guest CPUID filter missing
boot: ERROR — guest CPUID ECX store still has VMX
boot: boot gate failed
```

Diagnosis: naked GPR save/restore used abs32 `@0x4001efxx` while the UEFI
image is at `0x140000000`. Fixed by `v0.1.0-gprsfix`.

## gprsfix serial (Linux earlyprintk then INVPCID #UD)

```text
RAYNU-V-M3-IO-OK
RAYNU-V-M3-CPUID-OK
…
RAYNU-V-M3-LINUX-EARLY-OK
Linux version 6.12.40 …
Using GB pages for direct mapping
PANIC: early exception 0x06 … Code: … 66 0f 38 82 04 24
```

Diagnosis: `66 0f 38 82` = INVPCID; secondary Enable INVPCID was off → guest
#UD. Also add `nogbpages` for 512 MiB / 2 MiB precise EPT. Fixed by
`v0.1.0-invpcidfix`.

## invpcidfix serial (APIC-OK, no SHELL; earlyser off)

```text
Command line: … nogbpages …
…
printk: legacy bootconsole [earlyser0] disabled
RAYNU-V-M3-GTIMER3-OK
RAYNU-V-M3-APIC-OK
# no RAYNU-V-M3-SHELL-OK
```

Diagnosis: serial went blind when earlyser unregistered; tinyconfig
`SERIAL_8250_CONSOLE` may stall on TX IRQ under `noapic` (M3.19). Fixed by
`v0.1.0-keepconfix`.

## keepconfix serial (Run /init → stack guard)

```text
Command line: … earlyprintk=…,keep … 8250.nr_uarts=0 …
…
Run /init as init process
BUG: TASK stack guard page was hit …
Kernel panic - not syncing: Fatal exception in interrupt
```

Diagnosis: iron uses compacted XSAVE; secondary Enable XSAVES/XRSTORS was off
→ guest `xsaves` #UD in irq/FPU path → nested faults. Also naked `/init`
SHELL CPUID (no stack before hypercall). Next kit: `releases/v0.1.0-xsavesfix/`.
