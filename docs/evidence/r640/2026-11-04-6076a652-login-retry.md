## Why the revert did not fix it

The `d57ff3b9` evidence attributed the drop to the connection-shrinking
forcing a fresh login SYN that a starved coexist tick could not accept. The
revert removed that shrinking, and the drop still happened — so that
attribution was wrong. Two facts correct it:

- The whole SPA load produced **only two** TCP accepts (`slot=0`, `slot=1`).
  Firefox served the page, the operator GET, and the overview polls over
  those two keep-alive connections. The login POST **reused** one of them;
  it was not a fresh SYN, so SYN-reset starvation is not the cause.
- The failure is **transient and self-clearing**: the first reload failed,
  the next one seconds later worked. A genuine codec or auth fault would not
  heal on its own.

The transient lines up with the guest-egress bring-up. During
`network.target` the M8.9 egress arms function 1 (`:39`) of the **same**
BCM5720 and issues `boot: HOST-NIC BCM5720 reset…` with a GRC / bufmgr /
memarb reconfigure. The host listener on function 0 (`:38`, `:146`) shares
that chip. A connection in flight across that reset window stalls; `fetch`
throws, the webui's two instant retries both land inside the same window,
and the SPA shows **Account dropped**. Once egress bring-up finishes the
listener answers again, which is why the later reload loaded.

## Fix

`assets/webui.html` `postOp` now retries the login / save POST on a fresh
connection with a back-off (300 ms, 600 ms, 1 s, 1.5 s, 2.2 s — six tries
over ~5.6 s) and shows "Signing in…" between tries. A real `401` is still a
one-shot "Sign-in refused" (no retry); only a thrown `fetch` is retried;
"Account dropped" is shown only if every try throws. This rides out the
egress-reset window regardless of its exact source, which is the right
behaviour for a one-shot operator action over a listener that is briefly
busy. The server stack is unchanged from `6076a652` (the revert stays).

Coordinating the two-function BCM5720 bring-up so `:39` does not perturb
`:38` at all is the deeper cure; it is a larger, riskier change and is left
for a dedicated iron pass.
