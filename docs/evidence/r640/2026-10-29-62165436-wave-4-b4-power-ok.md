**Flash:** Lexar, label `RAYNUV`, front USB 2. Ubuntu 26.04 standing on UBUNTU0. Boot next was still saved, so each F11 started the Ubuntu tail by itself. No reinstall. No doorbell. UBUNTU0 was not written.

## Shut down

The operator clicked **Shut down**. COM2:

```text
boot: B4 sci
```

Ubuntu stopped services, unmounted `/boot` and swap, and printed:

```text
[  OK  ] Finished systemd-poweroff.service - System Power Off.
[  OK  ] Reached target poweroff.target - System Power Off.
reboot: Power down
```

The hypervisor then printed `boot: B4 power off` and left the guest down. The SPA stayed up in the Stage 46 hold. **Stop** was not clicked.

## Reboot

A later F11 of the same stick autostarted the tail again (`boot: B5 autostart start off=19327352832`) to `raynusrv2 login:`. The operator clicked **Reboot**. COM2:

```text
boot: B4 sci
reboot: Power down
boot: B4 power cycle
boot: RayNu-F guest reset requested src=acpi n=1 (F7; not ISO-INSTALL-OK)
boot: RayNu-F relaunch after reset (F7; not ISO-INSTALL-OK)
```

The guest ran its power-off, RayNu booted that disk again, and COM2 reached:

```text
Welcome to Ubuntu 26.04 LTS!
Ubuntu 26.04 LTS raynusrv2 ttyS0
raynusrv2 login:
```

**B4 lived.** Wave 4 stays open (D9, D10, H2).
