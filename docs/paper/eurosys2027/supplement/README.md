# Optional proofs supplement

`supplement.tex` is a short anonymous list of theorem names. EuroSys
reviewers may ignore it. The 12-page paper must stand alone.

```bash
cd docs/paper/eurosys2027/supplement
# copy acmart-friendly build:
pdflatex -interaction=nonstopmode supplement.tex
```

Upload `supplement.pdf` as HotCRP extra file, or skip and ship only
`paper/main.pdf`.
